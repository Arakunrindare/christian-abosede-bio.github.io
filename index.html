## scripts

Code library

# Bash pipelines — NGS analysis
umi_stranded_rnaseq_pipeline.sh
Bash
Full UMI-aware stranded total RNA-seq pipeline for the Takara SMARTer Pico kit. Covers FastQC, fastp UMI extraction, STAR alignment, umi_tools deduplication, and featureCounts with RF-strand settings.
View on GitHub
paired_end_rnaseq_pipeline.sh
Bash
Standard paired-end RNA-seq pipeline using Trimmomatic for adapter removal, STAR for splice-aware alignment, and featureCounts for gene-level quantification. Parameterised for any STAR-indexed genome.
View on GitHub
rnaseq_hisat2_star_pipeline.sh
Bash
Modular RNA-seq pipeline comparing two aligners (HISAT2 and STAR) and two trimmers (Trimmomatic and cutadapt). Includes optional SRA download, featureCounts, and HTSeq-count — uncomment the strategy you need.
View on GitHub
merge_fastq_lanes.sh
Bash
Safely concatenates paired-end FASTQ files across two sequencing lanes or runs. Matches samples by name, validates all four input files exist before merging, and reports any missing files clearly.
View on GitHub
bedgraph_to_bigwig.sh
Bash
Converts compressed bedGraph files to BigWig format for genome browser visualisation (IGV, UCSC). Handles decompression, coordinate sorting, and BigWig conversion in one loop.
View on GitHub
cellranger_count_pipeline.sh
Bash
Runs the 10x Genomics Cell Ranger count pipeline for single-cell RNA-seq GEX data. Includes a single-sample run and a multi-sample batch loop. Outputs filtered feature-barcode matrices ready for Seurat or Scanpy.
View on GitHub
rmats_splicing_analysis.sh
Bash
Detects differential alternative splicing events (SE, A5SS, A3SS, MXE, RI) between two conditions using rMATS. Configurable for any strandedness, read length, and genome annotation.
View on GitHub
rmats2sashimiplot_visualisation.sh
Bash
Generates sashimi plots from rMATS output to visualise differential splicing at specific loci. Supports all five rMATS event types, configurable scaling, and optional sample grouping for colour-coded plots.
View on GitHub
